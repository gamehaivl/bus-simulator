# Tải Bus Simulator Ultimate (Vô Hạn Tiền, MAP Việt Nam) v2.2.8

Bộ code tĩnh chuẩn GitHub Pages cho bài viết **Bus Simulator Ultimate** của GAMEHAIVL.

## Thành phần

- `index.html`: trang chính chạy ngay trên GitHub Pages.
- `bus-simulator-ultimate/index.html`: đường dẫn tĩnh theo slug gốc.
- `404.html`: trang lỗi thân thiện.
- `.nojekyll`: tránh GitHub Pages xử lý sai file/thư mục.
- `robots.txt`, `sitemap.xml`: file hỗ trợ SEO cơ bản.

## Tối ưu đã xử lý

- Không phụ thuộc WordPress, PHP, jQuery, Flatsome, wpDiscuz.
- CSS và JS được nhúng trực tiếp để giảm lỗi load asset.
- Giữ `title`, `description`, canonical, Open Graph, Twitter Card.
- Schema JSON-LD gồm Organization, WebSite, WebPage, Article, SoftwareApplication, FAQPage và BreadcrumbList.
- Ảnh dùng link tuyệt đối từ `https://gamehaivl.com` và có fallback khi lỗi.
- Responsive mobile, có menu, mục lục, bảng thông tin, FAQ và game liên quan.

## Cách upload lên GitHub Pages

1. Giải nén ZIP.
2. Upload **toàn bộ file bên trong thư mục** lên root repo.
3. Đảm bảo `index.html` nằm ngay ngoài cùng repo.
4. Vào **Settings → Pages → Deploy from branch → main / root**.
5. Đợi GitHub Pages build xong rồi mở URL được cấp.
